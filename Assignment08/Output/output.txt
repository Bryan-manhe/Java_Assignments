=== EMPLOYEE & MANAGER - SUPER KEYWORD DEMO ===

--- Employee Details ---
Employee ID: 1001
Name: Alice Johnson
Department: IT
Basic Salary: $50000.00
Salary: $50000.00

--- Manager Details ---
Employee ID: 2001
Name: Bob Smith
Department: IT
Basic Salary: $70000.00
Bonus Percentage: 15.0%
Team Size: 8 members
Total Salary (with bonus): $80500.00

--- Super Keyword Usage in Manager ---
1. super(empId, name, department, basicSalary) -> Constructor
2. super.displayDetails() -> Called parent method
3. super.basicSalary -> Accessed parent field
4. super.calculateSalary() -> Called parent method

=== KEY CONCEPTS ===
1. super() calls the parent class constructor
2. super.method() calls the parent class method
3. super.field accesses the parent class field
